# 批量压制重试与续做

## 目标

在批量压制和自动压制中保留每个文件的真实失败原因；单文件失败不阻断剩余文件；再次运行时跳过已成功生成且可被 FFprobe 读取的输出文件。

## 行为

- 每个待压制文件最多执行两次：首次与一次自动重试。
- 只有输出文件存在、FFprobe 可读取且视频流有效时，才视为已完成并跳过；缺失、零字节或无法探测的输出继续压制。
- 每个任务记录成功、跳过和失败数量，以及所有失败项的输入文件名和最终 FFmpeg 错误。
- 任务卡默认显示摘要；用户点击展开后显示所有失败项。
- 自动压制逐文件捕获错误，继续执行同剧目其余文件；下次扫描只处理未完成或失败的文件。
- 输入文件映射到同一输出路径时，在启动前报冲突，避免并行覆盖。

## 实现边界

前端负责调度、重试、输出存在性判断前的路径推导和失败明细持久化；Rust 继续负责一次压制与 FFprobe 验证。不会将 FFmpeg 失败伪装成成功，也不改变编码参数。

## 验证

覆盖首次失败后重试成功、两次失败后的全部错误展示、有效输出跳过、无效输出重压、自动任务某一文件失败后其余文件继续，以及重复输出路径拒绝。Windows 上用真实失败源文件确认展开信息与重跑跳过行为。
