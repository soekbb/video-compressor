# 自动压制：原位替换与增量补压

## 目标

自动压制成功后不再写入 `监控目录/影工输出/剧目名/`，改为用压缩结果**原位替换**源视频（同文件名）。持久化记录已处理剧目及其成功视频名；对已记录且目录创建时间不超过 2 天的旧剧目，扫描时只为**新增视频**建任务批量压制。Workbench 手动压制行为不变。

## 扫描与入队

- **新剧目**（`auto-state.json` 的 `done` 中无该剧目 `path`）：不论目录年龄，整夹视频入队批量压制。
- **旧剧目**（已有记录）：
  - 剧目文件夹创建时间 **> 2 天**：不再扫描其下视频明细，整夹跳过。
  - 剧目文件夹创建时间 **≤ 2 天**：对比目录内视频文件名与记录中的 `videoNames`；仅将未成功记录的文件入队（含曾失败需重试的文件）。
- **年龄判定**：使用剧目目录 birth time；不可用时回退顺序为 `birth → ctime → mtime`（实现时固定该顺序）。
- 现有排除规则保留（如 `影工输出`、`快压输出`、`_compressed`、隐藏目录）。

## 原位替换

1. FFmpeg 编码写到同目录临时文件：`.影工临时_<原名>_<短id>.<ext>`（扩展名与源文件一致）。
2. 校验输出有效（沿用现有 FFprobe 校验）。
3. 尝试原子替换到原路径。
4. 若失败且判定为占用：查找占用该文件的进程并结束（不得结束本应用自身 PID），再重试一次替换。
5. 仍失败：删除临时文件，保留原文件；将该文件记入剧目 `failures`，原因明确包含「文件被占用」。
6. 成功：压缩结果以**原文件名**落在原路径；文件名写入 `videoNames`，并清除同名 `failures` 项。

不创建 `影工输出` 目录；自动压制路径不再调用 `toBatchName` 生成 `_batch` 输出名。

## 状态结构（扩展 `auto-state.json`）

在现有 `AutoRecord` 上扩展：

| 字段 | 说明 |
|------|------|
| `path` / `name` | 剧目目录与名称（现有） |
| `completedAt` | 最近一次有成功压制的时间 |
| `videoCount` | 已成功替换的视频数量（`videoNames.length`） |
| `videoNames` | 已成功替换的视频文件名列表 |
| `failures` | 可选；最近失败明细：`{ name, reason, at }[]` |

**旧数据迁移**：缺少 `videoNames` 的记录视为「整剧已完成且无明细」。当该剧目目录创建时间 ≤ 2 天并被扫描时：将**当前目录内全部视频文件名**写入 `videoNames`（**不重压**），之后仅压制真正新增的文件。避免把旧流程已输出到「影工输出」、源文件仍留在原位的视频再压一遍。

任务粒度仍为「按剧目一个 auto 任务」；队列内仅含待压视频（新剧全量 / 旧剧增量）。

## 错误处理与记录时机

- 单文件失败（占用、编码失败等）：写入该剧目 `failures`，不写入 `videoNames`；同批次其余文件继续。
- **首次出现成功文件时**即将该剧目写入 `done`（含已成功的 `videoNames`）；之后每次成功追加文件名。全部失败且从未成功时不写入 `done`，下次扫描仍按新剧目整夹重试。
- 批次结束若仍有失败：任务状态标为失败，并带上现有 batch meta（成功/失败列表）；`done` 中已成功的 `videoNames` 保留。
- 下次符合扫描条件时，未成功文件会再次入队。
- 「清除记录」清空全部 `done`（含 `videoNames` / `failures`）。

## UI

- 自动压制页说明改为：成功后原位替换同名文件，不再提及 `影工输出/`。
- 已完成列表展示剧目名与已成功视频数；可展开查看 `videoNames` 与最近 `failures`（沿用现有列表风格，不新做复杂面板）。

## 实现边界

- 前端：扫描差分、入队、`AutoRecord` 读写与展示；自动压制输出目录改为剧目目录本身、输出名为原文件名。
- Rust：`list_drama_folders` 返回目录创建时间（或提供年龄判断所需字段）；压缩收尾支持「临时文件 → 杀占用进程 → 原子替换」；失败文案可区分占用。
- 不改变手动 workbench 的输出目录选择与 `_batch` 命名习惯。
- 不改变编码参数与质量预设逻辑。

## 验证

- 新剧目：整夹入队并原位替换；`videoNames` 写入成功文件。
- 旧剧目 ≤2 天：仅新增文件名入队；已成功名跳过。
- 旧剧目 >2 天：不扫明细、不入队。
- 无 `videoNames` 的旧记录：种子为当前全部文件名且不重压。
- 占用场景：杀进程后替换成功；杀不掉时原文件保留、`failures` 含「文件被占用」。
- 单文件失败后同剧其余文件继续；手动压制流程不受影响。
